# Verve

Parle, c'est déjà écrit. Verve transforme ta voix en texte corrigé, dans Teams, Outlook ou n'importe quelle application Windows.

## Installer

1. Télécharge **[Verve-Setup.exe](https://github.com/Jfaggio/verve-releases/releases/latest/download/Verve-Setup.exe)** : ce lien donne toujours la dernière version.
2. Ouvre le fichier téléchargé et clique sur **Installer**. Aucun droit administrateur n'est demandé.
3. Verve s'ouvre et prépare ton PC : il télécharge une fois les composants nécessaires (de 0,5 à 6 Go selon ta carte graphique). Tu peux continuer à utiliser ton ordinateur pendant ce temps.
4. Choisis ton bouton de dictée, par exemple un bouton latéral de la souris.

Si Windows affiche « Windows a protégé votre ordinateur », clique sur **Informations complémentaires**, puis sur **Exécuter quand même**. Ce message apparaît parce que le logiciel est récent.

## Utiliser

Place le curseur là où tu veux écrire, maintiens ton bouton de dictée, parle, puis relâche. Le texte apparaît, ponctué et corrigé.

L'icône Verve en bas à droite de l'écran, près de l'horloge, ouvre les réglages.

## Confidentialité

Par défaut, la reconnaissance vocale et la correction tournent sur ton PC : ta voix et tes textes n'en sortent pas.

## Configuration requise

Windows 10 ou 11, 64 bits, un micro. Une carte graphique NVIDIA de 6 Go ou plus donne la meilleure précision ; sans elle, Verve utilise un modèle plus léger.
